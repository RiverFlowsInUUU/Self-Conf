# 分流版 v1.0.2 更新日志

> 只动了分流版的**一个键** —— 删掉 Egern 侧那个并不存在的 `urls_disabled` 示例。配置行为对你没有任何可见变化。

## 分流版变更

- **移除 `Airport` 组里的 `urls_disabled` 示例键**（仅 Egern）。
  这个键在 Egern 官方文档里不存在（官方 `external` 组只有 `urls` / `filter` / `interval` /
  `tolerance` / `timeout` / `priorities` / `algorithm` / `update_interval` /
  `latency_test_url` / `block_quic` / `icon` / `hidden` / `prev_hop`）。
  它原本作为「示例」留着，而且值与被启用的 `urls` **完全相同** —— 万一哪天被解析成
  「禁用这个订阅」，`Airport` 会变空、走代理的流量会全断。没有依据的键，不如不留。

- 受影响范围：**仅 Egern 分流版**。Surge / mihomo 的分流版只是跟着升了版本号（三内核同号纪律），
  配置内容**一个字节没变**；懒人版完全未涉及。

## 需要你做的事

- **不用做任何事。** 这是一次清理，不是功能变更。重新导入与否都不影响你的使用。

## 适用版本

- 懒人版 v1.0.2（本次未改动）

- 分流版 v1.0.2
