# 懒人版 v1.0.5 → 分流版 v1.0.5 更新日志

> 本次只改了 Surge 的 DNS 设置（解决 leak test 显示中国运营商的问题），并精简了广告清单；其他内核、分流规则与策略组都不变。

## 共同变更

- **v1.0.5** 广告拦截清单精简为一份（RFU-Ads）。原先叠加的第二份广告清单已并入这一份，覆盖几乎不减少，但少了一次清单下载与更新，少一处可能误伤的来源。四端（Surge / Egern / mihomo / Stash）同步，无需你手动改动。

## 分流版变更

- **v1.0.5** 修好了 DNS 泄露国内运营商的问题：此前在 leak test 上可能显示阿里、电信等中国 ISP 的解析器出口，现在显示为境外解析器。原因是对多个加密 DNS 服务器并发查询、谁先返回用谁，其中那台国内服务器常先应答；本次移除了它，并让加密 DNS 连接走节点出口。解析更稳，隐私更好。

## 适用版本

- 懒人版 v1.0.5
- 分流版 v1.0.5
